# E-Commerce Capstone

## Description

A modern e-commerce website developed as a capstone project using AI-assisted development.

## Project Goals

- Build a responsive e-commerce experience.
- Practice modern frontend development.
- Use AI-assisted development throughout the project.

## Planned Features

- Product browsing and search
- Product categories
- Product details
- Shopping cart
- Responsive design
- Checkout flow

## Tech Stack

- HTML
- CSS
- JavaScript
- React
- Git
- GitHub

## Getting Started

The application source code has not yet been committed, so the project cannot currently be run locally. This repository will be updated with installation and development instructions once the React application is initialized.
