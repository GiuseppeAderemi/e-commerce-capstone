# E-Commerce Capstone — AI Development Instructions

## Project Overview

This project is a modern e-commerce website developed as a capstone project using AI-assisted development.

## Tech Stack

- HTML
- CSS
- JavaScript
- React
- Git
- GitHub

## Coding Conventions

- Use clean, readable, and maintainable code.
- Use descriptive names for variables, functions, and components.
- Keep React components small and reusable.
- Follow the existing project structure before creating new files.
- Avoid unnecessary dependencies.
- Write responsive layouts that work across desktop, tablet, and mobile devices.
- Keep styling organized and consistent.
- Do not modify unrelated files when completing a task.
- Explain significant changes when appropriate.

## Git Conventions

Use Conventional Commits.

Examples:

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation
- `refactor:` for code restructuring
- `chore:` for project maintenance
